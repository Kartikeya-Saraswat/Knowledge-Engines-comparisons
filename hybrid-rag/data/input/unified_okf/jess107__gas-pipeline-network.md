# Gas Pipeline Network

The first 1,700 km long Hazira-Vijaypur-Jagdishpur (HVJ) cross country gas pipeline is linked to Mumbai High and Bassein gas fields. It has various fertilizer, power, and industrial complexes in western and northern India. The pipeline network has expanded from 1,700 km to 18,500 km.
