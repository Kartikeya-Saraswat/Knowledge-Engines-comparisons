# Resource Planning

Resource planning involves identifying and inventorying resources across the country, surveying, mapping, and estimating resources quantitatively and qualitatively. It also involves developing planning structures with appropriate technology, skill, and institutional set up for implementing resource development plans. Resource planning in India has been a concerted effort since the First Five Year Plan.
