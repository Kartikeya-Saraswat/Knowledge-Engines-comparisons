# Nuclear and Thermal Power Plants in India

India has a number of multi-purpose projects like the Bhakra Nangal, Damodar Valley corporation, the Kopili Hydel Project etc. producing hydroelectric power. Thermal electricity is generated by using coal, petroleum and natural gas. The thermal power stations use non-renewable fossil fuels for generating electricity.
