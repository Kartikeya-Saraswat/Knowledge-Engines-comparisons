# Regional Connectivity Scheme (UDAN)

UDAN (Ude Desh ka Aam Nagrik) is a first-of-its-kind scheme designed to jump-start the regional aviation market. It encourages airlines to operate flights on regional and remote routes through enabling policies and extending incentives.
